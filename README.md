# Semana 5 - Tarea 1
Proyecto académico que implementa una aplicación web con arquitectura cliente-servidor, compuesta por un backend API en .NET y un frontend en Angular.
## Descripción
El sistema permite gestionar información mediante una API desarrollada en C#, la cual es consumida por una interfaz web construida con Angular. El objetivo del proyecto es demostrar la integración entre frontend y backend, así como la correcta organización de un sistema web completo.
## Estructura del proyecto
Semana5_Tarea_1
- Api_Web: Backend API (.NET / C#)
- Angular: Frontend (Angular)
## Tecnologías utilizadas
- C#
- .NET
- Angular
- TypeScript
- HTML
- CSS
## Ejecución
### Backend
1. Abrir la carpeta **Api_Web** en Visual Studio  
2. Ejecutar el proyecto  

### Frontend
1. Abrir la carpeta **Angular/Deber_Semana5/Deber5**  
2. Instalar dependencias:
npm install
3. Ejecutar:
ng serve
